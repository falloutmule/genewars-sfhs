Implemented for the workbench: pause and queued commands during pause; 0.5×/1×/2×/4× fixed-tick scheduling; overlap cycling and larger picking areas independent of footprints; desktop drag selection; touch tap/drag/pinch routing; select specialists/same role; keyboard groups and bookmarks; immediate order acknowledgement; command/route/placement/prerequisite/funds explanations; objective counts; alert subjects/ticks/focus/deduplication; restart; three manual saves; four recovery saves; JSON export/import; deterministic command replay; readable desktop/portrait/landscape panels; background pause; four category volume sliders.

Not yet implemented: canonical mission objectives/blocked-condition ledger, critical-alert autopause, reliable hold selection, visible destination markers, herd and production management, complete original help/codex, placement suitability overlay, building power previews, game voice subtitles/caption mappings, automatic campaign checkpoint saves, full sound lifecycle recovery, original strategic AI/pathing conformance, all job/creature state reasons, or physical phone validation. The category sliders currently control inspection audio, not game audio mixing.

No claim is made that the required improvements are complete. See the behavior matrix and change policy for which workbench behaviors are provisional.

# Pulper damage and retirement

Selector2 uses the existing446D0 damage,44380 retirement,43620 capacity and
43560 owner-mean services. The admitted native67 path retains pending51 and
stock54, updates completed counts, clears the actual two-cell footprint,
unlinks and cleans references, creates the actual crater job, and emits the
ordinary debris and final blast. It grants no stock refund or GOOP credit.
No collapse factory or selector-specific stop-audio event is added.

The source processing-front operation differs between processors: Pulper uses
8B2A0 operation0, which clears reserved dead-plant bit4; Recycler uses
operation1, which also clears eligible corpse reservations. The existing
campaign front helper already chooses this behavior from the actual selector.
Its call remains after footprint/completed-count cleanup and before building
unlink. The plant stays linked and active for its own subsequent lifecycle.

Private static comparisons cover15 selector2 cases across all three grades,
completed/incomplete retirement, partial depletion and small damage. All
3,775,500 compared numeric/map bytes, ordered effect/foreign-port requests and
caller RNG match over19,557 interpreted source instructions. Foreign effect,
crater, audio and processing-front bodies remain declared ports in this
particular comparison. Their host implementations are exercised separately;
the comparison does not execute the original program.

Five public synthetic tests exercise actual host destruction at every grade,
front cleanup and retained material, late recursive-factory rollback after
unlink/crater allocation, and a real37 projectile through the ordinary
campaign scheduler. The last test saves the destroyed state, continues both
copies and replays the whole callback segment. These checks do not establish
canonical mission acceptance.

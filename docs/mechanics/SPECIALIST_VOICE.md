##419E0 policy0

The preserved event arguments `[2,0,127,100]` map to descriptor byte19,
byte18, byte17 and dword12 respectively. Byte17 is the raw comparison/volume
byte used by the queue; dword12 carries the sample-rate percentage. The module
does not reinterpret them as a new effect play mode or distance policy.

`planSpecialistVoicePolicy0` applies these gates in source order:

1. Native owner must equal the selected player; runtime flags must contain4.
2. When a current speech descriptor exists, incoming byte17 must be at least
   its byte17. A lower value is discarded.
3.99EF3 compares the retained filename buffer with ASCII case folding. An
   identical filename is discarded even when the current descriptor pointer
   is null. The filename buffer is distinct from device playback state.
4. A different admitted filename produces interruption/removal intent for the
   current speech descriptor, copies the new filename buffer, and submits a
   descriptor to415C0. Policy0 does not enqueue in419E0's separate four-entry
   policy1 FIFO. Policy2 and other speech callers are outside this module.

`specialistVoiceDescriptor` constructs the actual speech-sentinel99 record
with flag64 and the bound SPE media key. This is the source's speech path;
numeric SOUND.DAT cue99 is never used as replacement audio. The host must
complete interruption/removal before allocation. The copied filename and old

##415C0 shared nine-slot allocator

`createSourceAudioAllocator` explicitly initializes conversion presentation
state. It does not claim to reconstruct an unobserved native audio image.
Each slot carries the known descriptor fields, a logical entity, a media
binding and the source five-byte deferred-stop sidecar. Native device handles
and undefined copied stack bytes are omitted.

`allocateSourceAudioDescriptor(state,descriptor,descriptorClasses)` returns a
new state, chosen slot or null, and any replaced descriptor. It does not read
devices or mutate the supplied state. Classification must come from admitted
105F60; the100-byte span SHA256 is
`c9d98fe3d69fd7ce139b109b8f3e242a8fc457948e94a1bd6b4847b15e2aab54`.

Below nine occupied descriptors, the first free slot wins and sidecar byte4
becomes100, retaining its other bytes.100 is a source marker, not a sound cue.
At capacity the two source branches differ:

- Incoming class0 considers only existing nonzero classes. It chooses the
  lowest byte17, then the larger class, retaining the first exact tie. Its
  initial best byte is127. The chosen slot's deferred-stop sidecar is
  overwritten with that old entity/cue.
- Incoming nonzero class takes the first nonzero-class slot with a lower
  byte17, or equal byte17 and larger class. A preexisting nonzero sidecar is
  retained. Only a zero sidecar receives the old entity/cue.

No eligible slot means capacity failure without fabricated playback. Incoming
sentinel99 updates the speech-slot binding only when accepted. The helper
`releaseSourceAudioDescriptor` removes a descriptor after a host stop or
completion notification and clears its speech pointer when appropriate.
Consumers must handle pending sidecars and their100 marker separately from
ordinary samples. No source audio-service polling latency, device handle
lifecycle,41780 per-cue cap, numeric417E0 admission or voice animation panel
state is inferred by this allocator alone.

## Journaling and validation

`journalSpecialistDamageVoice` stores serializable requests and pure policy
decisions with monotonic presentation sequences. Mapping/validation failure
leaves the journal unchanged. The campaign can instead journal only mapped
requests and run policy/allocation in its read-only browser consumer; live
device state must stay outside authoritative world state.

The campaign journals mapped requests only, with a monotonic voice sequence
retained by saves/replays. The UI consumes that journal through the device
adapter, including profile/classes/sample/capacity/device failure statuses,
owner/flag/policy gates, voice volume, pause/resume and dual-cursor reset.
Numeric effects and speech share the nine-slot allocator when the imported
class table is present. Ended/error/rejected play releases device capacity;
stale completion cannot clear a replacement. Immediate physical replacement
is an explicit presentation policy; source polling latency and41780 per-cue
caps remain unresolved. A submitted play attempt is not proof of audibility.

Public tests use synthetic tokens, containers, media strings and class arrays.
Five importer tests cover admission, pointer bounds, hashes and complete16-row
binding. Mechanic and device TypeScript tests cover all32 mappings, explicit prefixes and
missing media, source queue gates/case folding, journal atomicity, firstfree,
class0/nonzero replacement, sidecar retention, protected capacity and invalid
allocator state. The private read-only admitted-source check confirms the32
existing keys; it is not native audio timing or mission acceptance.

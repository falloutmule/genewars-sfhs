# Packed-four-bit ANB import

`tools/import-original/packed4.py` imports only the exact25 creature hashes admitted by the original6AC50/104494 loader evidence, plus the separately established BONES hash. A file extension or a plausible image never chooses this codec. GPF remains unadmitted. The original executable is not run, copied or embedded.

`anb_packed4(decoded, main_colors)` returns the same `sprites`, `frames`, `animations`, `imageBytes`, `paletteMode` fields as indexed8 ANB import. It preserves signed half component coordinates, flags, frame holds and complete animation trailing words. Mule contains115 sprite records and24 animations; BONES has11 sprites and5 animations. Metadata is bounded by the actual ANB sections, not by loose file-end reads.

The independent decoder treats positive signed controls as pixel counts consuming `ceil(count/2)` bytes, high nibble first. Odd low padding is discarded. Negative controls skip transparent positions; zero terminates each row. Literal nibble0 is opaque. Full clipped payloads are consumed before the next row. Short rows retain transparent remainder. Reads stop before sprite-table metadata and reject missing terminators or payloads. Empty descriptors, pixel budgets, section strides, component references and animation ranges have explicit bounds.

Nibble values are not MAIN.PAL indices0..15. The source neutral owner4 Mule/BONES wrapper uses palette banks192 and208, then the actual fade row, with screen parity and depth controlling the bank selection. The importer therefore returns both bank PNGs in JSON-safe `paletteAtlases` plus uncolored `packed4.indices` and `packed4.opacity` base64 streams. These streams concatenate tightly packed sprite rows in sprite-record order; opacity is0/1. `sprites` retain atlas coordinates; stream offsets are the prefix sum of each record's width\*height. `imageBytes` is explicitly the bank192 preview. It is not a claim of full runtime dither/fade/shadow composition. The caller must bind the actual owner, phase, fade, scale, flip, depth, origin and shadow state. Other admitted creature hashes have codec admission; their bank previews are explicitly marked as previews rather than silently claiming the Mule/BONES wrapper domains.

`decode_database` and `sprite_packed4` expose explicit structural decoding for synthetic tests and conformance. Production uses strict source and decoded-pixel hash admission for all26 resources. The pixel digest framing is the concatenation, for each record, of little-endian `(record:u32,width:u8,height:u8)`, all raw nibble bytes, and all0/1 opacity bytes. Independently verified Mule digest is`7a29fd10fa36495096f7af256b29117d5dbac16c23812f93335a1e5d403813c5`; BONES is`32d0057b0427dcdfc881def1403ff8abf8486c1ffccde293534d76ce79835e0f`. All26 expected digests are recorded in the importer. This compares complete decoded pixels/masks, not screenshots or original-execution rendering.

Public unit tests contain synthetic fixtures only. To check privately owned original inputs, set `GENEWARS_PACKED4_SOURCE` to the supported disc/installation source and run `python -B -m unittest discover -s tests/importer -p test_packed4.py -v`. The private tests pin all26 source hashes and every decoded pixel/mask through aggregate digests, plus Mule/BONES sprite/frame/animation counts. A separate local conformance audit compared all10,808,204 decoded index/mask bytes across2,709 sprites in26 resources against the preservation Rust `genewars-tools sprite4-decode` command; raw inputs/outputs and its receipt stay beneath ignored `.private/packed4-reference/`. Every resource also matched the preserved native per-sprite dimensions, consumed byte lengths and opacity counts.

Evidence consulted read-only: `research/ghidra/creature-evidence.json`, `bones-evidence.json`, `research/formats/anb-tab-structure.md`, `mule-render-contract.md`, `bones-render-contract.md`, `research/integration/sprite-corpus.json`, the bounded Rust `SpriteTable::decode_packed4`, and independent Mule/BONES pixel oracles. This import is a codec and asset-metadata step, not campaign or runtime-rendering acceptance.

## Neutral foreground palette selection

`src/render/packed4-palette.ts` implements the admitted owner4 foreground selector from `0x59470 → 0x94F30 → 0x93F80`. It exposes a deterministic CPU compositor and a Three.js shader binding. Both require raw nibbles, matching bank192/bank208 frame opacity, the original MAIN palette and the actual FADE row. FADE row0 is not an identity mapping in the admitted data; the bank PNG RGB values alone are therefore insufficient even for raw shade0. The decoded FADE table has16,384 bytes and SHA-256 `b1297e2c767573164d8f2f9266a0bfd9923bb1608d0d1a22f3f3682da03d5392`.

For destination `(screenX, screenY)` and indexed destination stride `pitch`, the alternate-bank bit is `clipFlagBit0 XOR (((screenY*pitch + screenX) XOR componentOriginX) & 1)`. This uses destination coordinates and the component's actual draw-left before clipping. Texture flips do not replace this with source-texel parity. The normal index is192+nibble or208+nibble. When `nibble < depth`, the index is instead `135 - (nibble >> 2)`, wrapping to a byte. Only then does FADE select the final MAIN.PAL RGB entry. Opaque literalzero remains visible.

The source depth is a health effect rather than camera distance: state>=26 forces0, otherwise it is the low byte of `8 - trunc(signed16(current6A)*8 / signed16(max64))`. Division by zero is rejected. Virtual height is signed32 physical field`+0x27` minus ground field`+0x11`. Raw shade0 selects fade row0 regardless of height; other shades select `min(31, rawShade + (virtualHeight >> 7))`. Negative rows and the unbound special parity recolor branch (`globalShadowMode==0`, nonzero effective shade and flags`+0x15 & 0x10`) reject explicitly. Global shadow mode is source global`0x115B5C`; no file offset in the mission/startup serialization has been established for its live value.

## Stage binding and presentation boundary

`SceneEntity.neutralPacked4` carries `{state,current6A,max64,rawShade,virtualHeight,flags15,globalShadowMode,clipFlagBit0}`. `SceneEntity.ownedPacked4` carries the separate kind1 player-owner context documented below. Exactly one context is required. Stage admits MULE/BONES foreground resources with one component in every frame; multiple component layouts and other creature art wrappers reject pending their own bindings. Missing fields never silently select the bank192 preview.

Stage composites paired256x256 bank frame planes at its existing `(128,160)` anchor, plus an identically placed/flipped raw-nibble texture. Shared textures and FADE lookup textures are cached. Each entity owns a material whose source health, fade and screen uniforms update without copying or advancing authoritative world state. An asynchronous scene request completes all input validation/decoding before visible entity changes; newer requests supersede older ones. Stage disposal releases its frame/index/lookup textures and materials.

The current Stage is a modern orthographic presentation: its existing8x8 billboards and canvas flips remain in place. One logical dither pixel is one CSS pixel, with physical WebGL pixels converted by renderer DPR. The component's projected actual draw-left is floored before viewport clipping; pitch640 preserves the original even row-stride parity. Screen uniforms refresh on every render, including pan, zoom and resize. This explicitly chosen geometry and viewport mapping does not claim the original640x480 framebuffer projection, wrapper scale or sampling. The original wrapper scale rule is256 when byte`+0x77==255` and byte`+0x76>=100`, otherwise `clamp(trunc(+0x76 * +0x77 / 100),150,256)`; Stage does not apply that native wrapper geometry yet.

The destination-remapping MAIN.GLA shadow pass and neutral special parity recolor branch remain separate work. Modern `globalShadowMode=0`/`clipFlagBit0=false` policy inputs must be labeled as presentation policy when not recovered from live source globals. CPU synthetic tests cover pointer parities, odd/even pitch, health boundaries, nonidentity fade, clipping, flips, opaquezero, shader texture orientation, Stage raw-plane placement and rejection before scene mutation. These checks are not original-execution pixel parity or mission acceptance.

## Player-owned foreground palette selection

`SceneOwnedPacked4Context` is explicit and orthogonal to the neutral wrapper. It adds actual native `owner`0..3, `sourceFrame`, unsigned native `entityId`(+0x0F), signed `timer6C` and unsigned `renderCounter7B` to the common raw state/health/shade/height/flags inputs. A selected ring or asset name never chooses an owner. `ownedPacked4Profile` resolves the source59470→94910/94D70→94400 foreground inputs without mutating the record. Its output has health depth, effective shade, one palette base and an explicit `fadeRow:number|null`.

The ordinary owner base is `(192 + owner*16) & 255`:192,208,224,240. Both pixel parities use this same base. The original raw nibble selects `base+nibble` unless it is strictly below health depth, in which case `135-(nibble>>2)` wins before fade. Packed4 bank PNGs supply the exact matching opacity planes; the shader obtains color from the raw nibble and original palette lookup, so an owned bank is never approximated by tinting an RGB preview.

Owned FADE gating differs from neutral rendering. Record flags`+0x15 & 2` or ordinary effective shade>=30 supplies a NULL fade pointer, represented by an identity lookup. Otherwise the actual FADE row is applied, including nonidentity row0. With nonzero effective shade and state18/0x12, source59825 replaces the row with `timer6C+31` when signed timer<30, or62 otherwise; state18 permits those rows through the ordinary>=30 gate, while flags&2 still selects NULL. Negative row indices reject. The parity highlight branch precedes these gates: global shadow mode0, nonzero shade, flags&0x10 and odd `(sourceFrame+entityId)` selects actual FADE row16 with the normal owner bank and health depth. Even parity takes the ordinary path.

Native byte7B values1..191 dispatch a separate generated remap table at116DA8; this table is not in the current imported profile. That path rejects explicitly rather than substituting the ordinary owner bank. Values0 and192..255 take the ordinary owner palette branch. The highlight branch bypasses7B dispatch as in source. This is a bounded foreground palette implementation; native geometry, MAIN.GLA shadowing, generated7B remaps and lifecycle icons remain outside its acceptance.

`createOwnedPacked4Material`/`updateOwnedPacked4Material` share the raw/opacity sampler contract with neutral materials, using zero bank stride for the owned case. Material transitions reset the bank base/stride explicitly. Sampler validation inspects only the four named textures; numeric frame metadata such as `componentLeft` is not a sampler. Stage shader-compilation errors throw through the presentation/page error path instead of being counted as successful rendering.

The23 public synthetic palette/Stage tests cover every owner/nibble, health boundaries, ordinary FADE/NULL gates, state18 rows, actual frame/ID highlight parity,7B rejection, raw flips/opacity and owner-neutral transitions. The ignored `.private/owned-packed4-browser.json` receipt records an offline read-only WebGL check of12 scenes from preserved owner0..3 records and wrapper-height fixtures. All2640 foreground pixels agree with the actual projected raw-nibble, source FADE/identity and MAIN lookup within one RGB rounding unit; page/console/network errors are empty. An intentionally invalid shader confirms Stage promotes compilation failure. This verifies modern Stage visibility and palette lookup, not source framebuffer geometry/shadow parity or mission acceptance.

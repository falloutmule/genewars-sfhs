# Campaign building damage binding

`damageCampaignBuilding(world,pack,slot,damage,attackerId|null,services)` binds the released446D0 mechanic to the live campaign. It mutates an already isolated complete world. The caller owns the outer transaction, including recursive blast damage, actor/creature changes, native pools, players, terrain, RNG and queued presentation. Missing dependencies throw instead of committing a partial substitute. The adapter does not open an independent partial transaction.

`services.effectOptions(currentWorld)` is required and supplies the actual shared effect allocation, ordered blast query and recursive damage services. The adapter uses `createStagedDestructionEffect` for source46, debris27..31 and the final code5 area blast. It uses the real32-slot `createCollapse` for family6 selector3 and the actual25×176 `createCraterJob` for79160. Every permitted capacity failure is returned in the typed allocation receipt; it does not prevent building retirement. The adapter updates raw shared effect count3554 and synchronizes the source countdown changed by successful blast construction.

The crater constructor stages its argument. The adapter supplies only its actual numeric roots `{missionPrefix,terrain,rng}`, then commits those writes in place. It preserves the complete host's native array, every native building record, player/raw arrays, mission-prefix object, terrain object and RNG object across this call. This prevents a nested crater from replacing source-like pointers held by another callback. The active crater job and its viewport invalidations are returned; the ordinary79220 pass performs later height, shade and zone work.

Retirement unlinks the building's logical spatial node and synchronizes live neighbor links, then executes724C0 while the dying native kind is still4. Source reference-kind clears preserve stale index operands. A launched packet loses only its actual native destination kind and corresponding motion-cache target; its identity, velocity, payload and economy packet remain alive to finish normal decay. The building is removed from construction/economy active projections, which also prevents a later Genepod production callback. Native production/queue fields remain in the inactive67-byte afterimage. No separate fabricated Genepod state is introduced.

If a modern construction task still refers to the removed building, `services.cancelConstruction(currentWorld,actorId)` is required. Root binds the actual construction cancellation and consumes its animation/motion/audio receipt. This bridges the existing normalized construction host to native724C0; merely dropping the building or clearing a boolean would leave its next `buildingAt` call invalid. The adapter verifies that the target binding was released and clears normalized egress references. It does not demolish another building, refund paid construction or invent a terrain-job cancellation.

After source writes, player funds, GOOP, completed counts and acquired ownership mask are read from actual raw fields into their projections. Live building health/completion, energy and established native flag masks are mirrored into construction/economy views. Capacity and maximum operational Genepod grade come from raw5E6/6E1; the adapter preserves the source's pre-unlink capacity afterimage rather than immediately recomputing it from the reduced building list. Acquired ownership bits likewise remain set when completed count reaches zero. Source pointers and original source serialization buffers are not rewritten.

Stop/depletion numeric audio requests are queued in staged `AudioState`, including the actual initial playback-rate percentage. Ordered source events and audio requests are retained in the receipt. `services.onEvent` can enqueue typed selection/message presentation; it must not perform external side effects. A destroyed-building name-index/filename message is not reinterpreted as a numeric WAVE cue. Its full media binding remains an explicit host presentation obligation. `selectedBuildingSlot` is optional because the modern UI derives selection outside authoritative simulation state. `gameplayRunning` can bind the actual gameplay-screen state; otherwise the normalized active phase is used. The admitted depletion branch checks source gameplay class116974==1863A2, not global flags bit4; the latter belongs selector12, outside this family.

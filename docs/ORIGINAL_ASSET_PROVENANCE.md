Original artwork, text, maps and sound are copyrighted content outside the conversion-code license. The importer derives private resources locally. `.private/`, `dist/`, packs, binary captures and dependency caches are ignored. Original input hashes/resource names may be documented as identification metadata; original content bytes and personal absolute paths do not belong in public source.

The leak check inspects public candidate files and tracked private paths; it compares locally available original/derived hashes, flags binary asset extensions/signatures, embedded data URIs, personal paths and common secret patterns, and checks notices. This is defense in depth, not a legal rights determination or universal binary-content detector. Run it before commits, pushes and release preparation. No deployment workflow is supplied. The repository has no remote publication performed by this task.

No archival Rust source, decompilation or proprietary code is copied or blanket relicensed. New Python readers independently express the documented formats; archived decoder hashes and structural results are used for private conformance. Battle Drones adaptations have separate Apache attribution.
